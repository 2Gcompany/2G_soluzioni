# Protocollo seriale

Esempio di riga inviata all'Arduino: `S90 G90 P90 C40`

| Lettera | Giunto | Valori |
| ------- | ------ | ------ |
| S | Spalla | 0–180° |
| G | Gomito | 0–180° |
| P | Polso | 0–180° |
| C | Pinza (apertura) | 0–100 % |

Le lettere sono un esempio. Prima di collegare il braccio vero vanno confrontate con lo sketch Arduino reale.
