# 2G Soluzioni

Teaching material and projects of the class startup.

## Language

**Lezione**:
A folder under `lezioni/` holding the material of one topic; it is published on the site when it contains an `index.html`.
_Avoid_: corso, pagina, modulo

**Sito**:
The public website on GitHub Pages that lists the lessons and serves each one at its own address.
_Avoid_: portale, sito contenitore
