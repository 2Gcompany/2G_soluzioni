# 2G Soluzioni

Repository della mini startup della classe 5E dell'ITIS Galileo Galilei.

## Struttura

- `lezioni/` – materiale delle lezioni, una per cartella
- `progetti/` – i progetti della startup, uno per cartella
- `wiki/` – documentazione e appunti condivisi
- `installazione_opencode/` – guida e strumenti per installare opencode

## Progetti

- [Backup Foto (rsync-ui)](progetti/rsync-ui/README.md) – interfaccia semplice per copiare le foto da scheda SD o fotocamera a un disco di backup; prototipo cliccabile.

## Lezioni

- [Braccio robotico](lezioni/braccio-robotico/README.md) – simulazione di un braccio a tre giunti con pinza e comandi seriali per Arduino.
- [C# File & Stream](lezioni/csharp-file-stream/index.html) – corso in 9 tappe sulla gestione dei file in C#, con codice interattivo e simulatore console.
- [Corso di Inglese](lezioni/inglese/Corso%20di%20Inglese%20in%20Quinta%20Superiore.pdf) – dispensa del corso di inglese per la quinta superiore.
- [Derivate](lezioni/matematica/derivate/README.md) – guida alle derivate di funzione, con esempi interattivi, in un unico file HTML.
- [Stampa 3D (Layer Lab)](lezioni/stampa-3d/README.md) – sito interattivo che spiega la stampa 3D agli studenti di quarta: undici strati, simulatori di G-code e slicer, quiz finale.
- [Yu-Gi-Oh!](lezioni/yugioh/README.md) – guida rapida e chiara per capire il gioco in pochi minuti, tutta in un file.

## Strumenti

- [Opencode](installazione_opencode/README.md) – guida all'installazione del tool opencode nel terminale del Codespace.
- [Sito delle lezioni](https://panicerid.github.io/2G_soluzioni/) – elenco online delle lezioni; lo genera `sito/` (in locale: `cd sito && npm install && npm run dev`).
