# Calcolo delle Derivate

**Una guida semplice e chiara che include esempi interattivi su cos'è e come si calcola la derivata di una funzione.**

</div>


## Descrizione

Questo progetto è una guida alle derivate di funzione, contenuta **in un unico file `html`**.

**Non richiede installazioni** o un dispositivo specifico: basta un browser come Chrome o Firefox per aprirlo.

## Come consultarlo

1. Scaricare il file `index.html` dalla cartella `progetti/matematica/derivate`
2. Fare doppio clic sul file per aprirlo. Nel caso non venisse aperto da un browser, fare clic destro e selezionare "Apri con" > (browser a propria scelta)

## Contenuti

| # | Sezione | Descrizione |
|---|---------|---------------|
| 1 | **Cos'è la Derivata?** | Definizione e introduzione alle derivate |
| 2 | **Costanti e Funzioni Lineari** | Come derivare costanti, rette e moltiplicazioni per uno scalare |
| 3 | **Potenze** | Come derivare potenze e i trucchi per gestire radici e frazioni |
| 4 | **Esponenziali** | Come derivare le funzioni esponenziali |
| 5 | **Logaritmiche** | Come derivare il logaritmo naturale e di qualsiasi base |
| 6 | **Goniometriche** | Come derivare le funzioni goniometriche: cos, sin, tan |
| 7 | **Algebra delle Derivate** | Regole per combinare più funzioni tra loro: somma, prodotto, quoziente |
